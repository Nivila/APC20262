# Exercícios de Programação em C

## Descrição

Nesta atividade, foram propostos exercícios introdutórios de programação em linguagem C, com base no material *C Language — Cheatsheet com Exercícios*, até a linha 727.

O objetivo é compreender a estrutura e o funcionamento da linguagem C, observando a execução dos programas, o comportamento das variáveis e as operações realizadas.

## Conteúdos abordados

- **Exercício 1:** Estrutura de um programa e pilha de chamadas.
- **Exercício 2:** Tipos primitivos, tamanhos e conversões de dados.
- **Exercício 3:** Declaração e inicialização de variáveis.
- **Exercício 4:** Operadores aritméticos, incrementos e operações com bits.
- **Exercício 5:** Estruturas condicionais e de repetição (`if`, `else`, `for`, `do-while` e `switch`).
- **Exercício 6:** Funções, recursividade e passagem de parâmetros por ponteiros.
- **Exercício 7:** Arrays, matrizes e manipulação de seus elementos.

## Ferramenta utilizada

[Python Tutor — Visualizador de C](https://pythontutor.com/c.html)

A ferramenta permite acompanhar a execução dos códigos passo a passo, facilitando a compreensão das variáveis, funções e estruturas de memória.

## Objetivo da atividade

Praticar os conceitos fundamentais da linguagem C e compreender como os programas são executados, relacionando os conhecimentos de programação com a utilização de memória e o processamento de dados.

## Referência

Material: *C Language — Cheatsheet com Exercícios* (linhas 1 a 727).
