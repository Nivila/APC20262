
# Exercícios de Programação em C

## Descrição
Nesta atividade, foram propostos exercícios de programação em linguagem C, com base no material **C Language — Cheatsheet com Exercícios**, dando continuidade aos conteúdos estudados anteriormente.

O objetivo é aprofundar a compreensão da linguagem C, explorando a manipulação de strings, ponteiros, alocação dinâmica de memória, estruturas de dados, entrada e saída de arquivos e outros recursos da linguagem.

## Conteúdos abordados
- **Exercício 8:** Strings, manipulação de caracteres e funções da biblioteca `<string.h>`.
- **Exercício 9:** Ponteiros, desreferenciação, aritmética de ponteiros e ponteiros para ponteiros.
- **Exercício 10:** Alocação dinâmica de memória com `malloc`, `calloc`, `realloc` e `free`.
- **Exercício 11:** Structs, unions, organização de dados e acesso aos membros.
- **Exercício 12:** Enums, estruturas enumeradas e operações com flags.
- **Exercício 13:** Entrada e saída de dados, formatação e manipulação de arquivos.
- **Exercício 14:** Pré-processador, macros e compilação condicional.
- **Exercício 15:** Escopo de variáveis, duração de armazenamento e uso de `static`.
- **Exercício 16:** Boas práticas de programação e manipulação segura de buffers.
- **Exercício 17:** Ponteiros para funções, callbacks e ordenação com `qsort`.
- **Exercício 18:** Listas simplesmente ligadas, alocação dinâmica de nós e manipulação de estruturas de dados.

## Ferramentas utilizadas
**Python Tutor — Visualizador de C**

A ferramenta permite acompanhar a execução dos códigos passo a passo, facilitando a compreensão das variáveis, dos ponteiros, das funções e das estruturas de memória.

**GCC (GNU Compiler Collection)**

Utilizado para compilar e executar os programas, permitindo também a identificação de avisos e erros durante o desenvolvimento.

## Objetivo da atividade
Praticar e aprofundar os conceitos da linguagem C, compreendendo o gerenciamento de memória, a manipulação de dados, o funcionamento dos ponteiros e a implementação de estruturas de dados dinâmicas, desenvolvendo códigos mais seguros e organizados.

## Referência
